# A1 mini + Top-AMS：Bambu Studio 完整用户操作流程

> 本文只讲用户如何操作，不讲代码原理。  
> 当前仓库推荐组合：A1 mini + 无原厂 AMS Lite + Top-AMS + Bambu Studio。

## 一、到底要替换哪些 G-code

当前仓库的结论是：

| Bambu Studio 设置 | 是否替换 | 使用内容 |
| --- | --- | --- |
| 机器启动 G-code（默认） | **不替换** | 保留所用 Bambu Studio 版本自带的 A1 mini 默认内容 |
| 机器启动 G-code（可选自动首料） | **显式选择时完整替换** | [A1mini启动_topams首料_20260513.gcode](./A1mini启动_topams首料_20260513.gcode) |
| 换料 G-code | **完整替换** | [A1mini换料_topams版本.gcode](./A1mini换料_topams版本.gcode) |

请特别注意：

- [A1mini快速启动.gcode](./A1mini快速启动.gcode) 是第三方快速启动脚本，不是当前 Top-AMS 的首料选择脚本。
- 不要因为其他 Top-AMS 教程要求同时替换两个 G-code，就把其他项目的启动 G-code 与本仓库的换料 G-code 混用。
- 默认方案不会在开机时自动选择第一种料。开始打印前，要提前装好首个打印耗材，并在 Top-AMS Web 中确认正确的“当前通道”；固件不会默认猜成通道 1。
- 可选自动首料模板以官方 `20260513` A1 mini 模板为基线，只加入独立的 `9–16` 首料标记。首次安装和排障仍建议先使用默认方案。

## 二、首次安装：只做一次

### 第 1 步：准备文件

在电脑上找到：

- [A1mini换料_topams版本.gcode](./A1mini换料_topams版本.gcode)
- 可选：[A1mini启动_topams首料_20260513.gcode](./A1mini启动_topams首料_20260513.gcode)

用记事本、Visual Studio Code 或其他纯文本编辑器打开。暂时不要修改内容。

### 第 2 步：打开 Bambu Studio

1. 启动 Bambu Studio。
2. 进入“准备”页面。
3. 在左上角“打印机”处选择：
   - `Bambu Lab A1 mini`
   - 与机器一致的喷嘴直径，例如 `0.4 nozzle`
4. 建议切换到“高级”或“专家”模式，确保能看到完整打印机设置。

### 第 3 步：复制一个专用打印机预设

1. 在“打印机”预设右侧点击“编辑”图标，通常是铅笔或齿轮。
2. 如果当前是不可修改的系统预设，点击“另存为”或保存图标。
3. 新预设命名为：

   ```text
   A1 mini 0.4 - Top-AMS
   ```

4. 后续多色打印只使用这个预设；普通打印仍可切回官方 A1 mini 预设。

### 第 4 步：选择启动模式

1. 在打印机设置中进入：

   ```text
   机器 G-code / Machine G-code
   ```

2. 找到：

   ```text
   机器启动 G-code / Machine start G-code
   ```

3. 首次使用请**不要替换、不要清空，也不要粘贴 `A1mini快速启动.gcode`**，使用“官方启动 + 人工预装并确认首料”。
4. 如果以前已经改过启动 G-code，最稳妥的处理方式是：
   - 重新复制当前 Bambu Studio 的官方 A1 mini 系统预设；
   - 再只修改换料 G-code。
5. 只有在闭环换料已通过小模型测试后，才可另建一个预设，把机器启动 G-code 完整替换为 [A1mini启动_topams首料_20260513.gcode](./A1mini启动_topams首料_20260513.gcode)。不要与其他项目的启动模板混用。

### 第 5 步：完整替换换料 G-code

1. 在同一个“机器 G-code”页面找到：

   ```text
   换料 G-code / Change filament G-code
   ```

2. 先把原有内容复制到一个备份文本文件。
3. 删除该输入框中的全部原内容。
4. 复制 [A1mini换料_topams版本.gcode](./A1mini换料_topams版本.gcode) 的全部内容。
5. 粘贴到“换料 G-code”输入框。
6. 保存打印机预设。
7. 关闭设置窗口。

不要只复制其中的 `M140` 或 `M400 U1`。必须使用完整换料模板。

### 第 6 步：确认正在使用 Top-AMS 预设

回到“准备”页面，检查左上角打印机名称必须是：

```text
A1 mini 0.4 - Top-AMS
```

如果仍显示官方 A1 mini 预设，本次切片不会使用刚才保存的 Top-AMS 换料代码。

## 三、首次安装：连接 Top-AMS

### 第 1 步：打开 Top-AMS Web

1. 确认 ESP32 和 A1 mini 已连接到同一个局域网。
2. 在浏览器输入 ESP32 的 IP：

   ```text
   http://ESP32的IP
   ```

### 第 2 步：连接打印机

在“网络配置”中填写：

1. A1 mini 的 IP 地址。
2. A1 mini 的设备序列号。
3. 打印机显示的局域网访问码/MQTT 密码。
4. 点击“连接打印机”。

### 第 3 步：检查连接

进入“系统诊断”，确认：

- MQTT 显示已连接。
- 最近收包时间持续更新。
- 页面没有持续显示“数据超时”。

修改过打印机 IP、序列号或密码后，重启 ESP32 再检查。

## 四、首次安装：标定物理通道

### 第 1 步：固定编号

给每个物理进料器贴上清楚的编号：

```text
通道 1、通道 2、通道 3……
```

Bambu Studio 的“耗材 1”永远对应物理通道 1，“耗材 2”永远对应物理通道 2。

### 第 2 步：检查每个通道的方向

在 Top-AMS Web 的“通道管理”中，对每个通道操作：

1. 点击“正转”，料线应朝打印头方向移动。
2. 点击“反转”，料线应朝料盘方向移动。
3. 如果方向相反，切换该通道的“反向输出”。
4. 再测试一次。

### 第 3 步：填写通道参数

为每个通道填写：

- 材料名称。
- 颜色。
- 进料时间。
- 退料时间。
- 换料温度。

第一次不要直接打印大型模型。进料时间和退料时间要用小测试逐步调整。

### 第 4 步：理解“当前通道”

“当前通道”表示现在真正进入打印头的那一卷料。

例如：

- 打印头内是通道 1 的白色 PLA：选择“通道 1”。
- 打印头内是通道 3 的黑色 PETG：选择“通道 3”。
- 打印头内没有料：选择“无耗材”。

这个选项设置错误可能导致退错料或两条料同时进入。

## 五、每次打印：在 Bambu Studio 中建立耗材

### 第 1 步：选择专用打印机预设

打开 Bambu Studio“准备”页面，选择：

```text
A1 mini 0.4 - Top-AMS
```

每次切片前都要检查一次。

### 第 2 步：按物理通道添加耗材

在左侧“耗材”列表中点击 `+`，按实际通道添加耗材。

示例：要使用物理通道 1、2、3：

| Bambu Studio | 实际料盘 |
| --- | --- |
| 耗材 1 | Top-AMS 通道 1 |
| 耗材 2 | Top-AMS 通道 2 |
| 耗材 3 | Top-AMS 通道 3 |

每个耗材分别设置正确的：

- 材料类型，例如 PLA、PETG。
- 喷嘴温度。
- 热床温度。
- 颜色。

注意：

- 不要点击“同步 AMS”来同步 Top-AMS。Top-AMS 不会被 Bambu Studio 识别为原厂 AMS。
- 如果最高要使用通道 4，应保留耗材 1–4 的编号，不要删掉耗材 2、3 后把原通道 4 变成“耗材 2”。
- 切片器中的颜色只是显示和选料依据，真实料盘仍由用户摆放。

## 六、每次打印：给模型选择耗材

根据模型类型选择下面一种方式。

### 方法 A：整个模型使用一种耗材

1. 在对象列表中选中模型。
2. 选择对应耗材编号或颜色。
3. 确认模型整体变成目标颜色。

这种方式不会产生换料，适合先验证单色打印。

### 方法 B：多个零件分别用不同耗材

1. 导入多零件模型或 3MF。
2. 在右侧“对象”列表展开模型。
3. 选中某个零件。
4. 给它选择耗材 1、2、3 等。
5. 对其他零件重复操作。

### 方法 C：给模型表面涂色

1. 选中模型。
2. 点击顶部“颜色绘制/Color Painting”工具。
3. 选择要使用的耗材颜色。
4. 使用填充、笔刷、三角面或高度范围工具涂色。
5. 点击“完成”退出涂色。

### 方法 D：在某一层开始换色

1. 先添加至少两种耗材。
2. 点击“切片单盘”。
3. 进入“预览”。
4. 在右侧层高滑块移动到目标层。
5. 在滑块的 `+` 位置右键，选择“更换耗材/Change Filament”。
6. 选择目标耗材编号。
7. 重新切片或让 Bambu Studio 更新预览。

不要用普通“暂停”代替“更换耗材”。普通暂停不会提供新的 `next_extruder` 通道编号。

## 七、每次打印：设置冲刷体积

1. 在耗材列表附近打开“冲刷体积/Flushing volumes”。
2. 可以先使用自动计算或默认值。
3. 第一次双色测试不要把冲刷量设得过低。
4. 切片后检查冲刷塔和废料量。
5. 实际打印确认颜色干净后，再逐步减少冲刷量。

深色换浅色通常需要更多冲刷。不同材料之间还要确认打印温度和粘接兼容性。

## 八、每次打印：切片与预览

### 第 1 步：切片

点击：

```text
切片单盘 / Slice Plate
```

如果出现“自定义 G-code 变量不存在”或“换料 G-code 解析失败”，不要发送打印。检查：

- 是否使用了推荐模板的完整内容。
- Bambu Studio 版本是否与模板兼容。
- 是否误改了方括号、花括号或条件语句。

### 第 2 步：检查预览

在“预览”页面确认：

1. 模型颜色和耗材编号正确。
2. 第一层最先使用的是哪一个耗材。
3. 每个换色位置正确。
4. 冲刷塔和冲刷路径已生成。
5. 没有意外的频繁换色。

记住第一种耗材的编号。发送打印前要把它装入打印头。

### 第 3 步：第一次安装后检查 G-code

首次测试、升级 Bambu Studio 或修改模板后，导出切片结果并搜索：

```text
;EXT
```

例如从耗材 1 换到耗材 2，应看到：

```gcode
M140 S2;EXT
```

同一换料段后面还应存在：

```gcode
M400 U1
```

如果没有 `;EXT`，说明没有使用 Top-AMS 预设或模型没有产生真实换料。

## 九、每次打印：准备首个耗材

使用默认官方启动模式时不会自动选择第一种料，所以这一步不能跳过。使用可选自动首料模板时，也必须先确认页面已取得真实传感器状态；已有料但通道未知时系统会保持暂停等待人工确认。

假设预览显示第一个使用的是“耗材 3”：

1. 确认实际材料装在 Top-AMS 物理通道 3。
2. 在 Top-AMS Web 中点击通道 3 的“装载”，或者按已验证的方法手动装入通道 3。
3. 确认喷嘴已经能挤出通道 3 的材料。
4. 在 Web 的“当前通道”选择“通道 3”。
5. 确认其余料线位于已经标定的待机位置。

如果第一种料已经在打印头内，只需确认 Web“当前通道”正确，不要重复装载。

## 十、每次打印：发送到 A1 mini

1. 点击：

   ```text
   打印单盘 / Print Plate
   ```

2. 选择正确的 A1 mini。
3. 如果发送窗口出现“使用 AMS/Enable AMS”：
   - 没有原厂 AMS Lite 时不要勾选；
   - 不要把 Top-AMS 虚假映射成 AMS Lite 槽位。
4. 按需要选择调平、流量校准和延时摄影。
5. 再确认一次第一耗材已经装好。
6. 点击发送/打印。

如果当前 Bambu Studio 版本因为没有检测到原厂 AMS 而拒绝发送多耗材任务：

1. 不要伪造 AMS 连接。
2. 先确认使用的是仓库已知兼容的 Bambu Studio 版本；项目历史说明推荐过 `2.0.1.50`。
3. 也可以改用支持手动多材料流程的 OrcaSlicer。
4. 更换切片器版本后重新执行小型双色测试。

## 十一、打印过程中应该看到什么

第一次正式测试只使用一个小型双色模型，并在机器旁观察。

正常过程：

1. A1 mini 使用提前装好的首个耗材正常开始打印。
2. 到换色位置时，打印机移动到换料位置并暂停。
3. Top-AMS 退出旧料。
4. 旧通道电机反转。
5. 新通道电机正转进料。
6. Top-AMS Web 的“当前通道”变成新通道。
7. 打印机自动恢复。
8. A1 mini 执行冲刷、擦嘴并继续打印。

若出现错误：

- 退错通道：立即停止，检查 Web“当前通道”。
- 新通道不进料：暂停并检查电机方向、进料时间和料路。
- 一直暂停：检查 Top-AMS Web 的 MQTT 状态和诊断日志。
- 颜色不对：检查 Bambu Studio 耗材编号与物理通道映射。
- 页面显示卡料、未确认出料、MQTT 超时或阶段超时时：电机应已停止，打印应保持暂停；排障后手动重试，最后由用户在打印机端恢复。

## 十二、最简日常检查单

每次点击“打印单盘”前确认：

- [ ] 使用的是 `A1 mini 0.4 - Top-AMS` 打印机预设。
- [ ] 机器启动 G-code 使用默认官方内容；若明确启用自动首料，则使用仓库 `20260513` 可选模板。
- [ ] 换料 G-code 是仓库推荐的 Top-AMS 完整模板。
- [ ] Bambu Studio 耗材编号与物理通道编号一致。
- [ ] 模型已正确选料或涂色。
- [ ] 预览中的首个耗材已经装入打印头。
- [ ] Top-AMS Web“当前通道”正确。
- [ ] MQTT 显示已连接。
- [ ] 最大进料时间、完整退料时间已经通过小模型验证。
- [ ] 没有勾选不存在的原厂 AMS。

完成以上检查后再发送打印。
