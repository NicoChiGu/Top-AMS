# Change: 增加按通道配置的电机反向输出

## Why
不同电机或机械安装可能导致实际进退料方向与固件定义相反。用户需要在不修改固件引脚配置的情况下，从 Web 界面独立校正每个通道的输出方向。

## What Changes
- 为每个电机通道增加默认关闭、持久化保存的反向输出配置。
- 在统一电机控制出口根据通道配置交换正向与反向 GPIO，覆盖自动与手动动作。
- 在通道管理界面增加方向开关，并在系统忙碌时阻止修改。
- 保持现有电机命令、进退料时间和未配置通道的行为不变。

## Impact
- 影响的规范：`motor-control`
- 影响的代码：电机配置、电机运行控制、WebSocket 配置处理、通道管理界面和发布说明
