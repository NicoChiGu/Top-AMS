# Change: 增加运行时系统诊断

## Why
当前 Web 页面只能看到单条即时日志和少量连接状态，无法还原设备资源、MQTT 链路或最近一次自动换料在何处失败。用户排障通常需要连接串口并重新复现，成本高且容易丢失故障前因。

## What Changes
- 在 Web 系统诊断页提供固件、重启、堆内存、Wi-Fi、MQTT、WebSocket 和关键运行状态快照。
- 使用仅驻留 RAM 的 64 条结构化环形日志，支持实时查看、筛选、暂停滚动、清空、复制和下载。
- 记录最近一次自动换料的六阶段时间轴、阶段耗时、跳过分支和最近超时点。
- 统一诊断日志入口并禁止输出 MQTT 密码、设备序列号和完整 MQTT 消息正文。

## Impact
- 影响的规范：`runtime-diagnostics`
- 影响的代码：运行诊断模块、MQTT 事件统计、自动换料流程、WebSocket 协议、Web 系统诊断页和发布构建版本信息
- 兼容性：保留现有 `data[]` 配置协议、顶部 Wi-Fi 状态、电机时序和 MQTT 控制命令
